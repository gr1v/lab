# Определение
### Алгоритм муравьиной колонии для задачи о рюкзаке 
— это алгоритм, который на каждом шаге выбирает предмет для добавления в рюкзак на основе феромонов и удельной ценности, чтобы максимизировать общую ценность при ограничении по весу.

### Объяснение работы алгоритма:

Инициализация феромонов
Алгоритм создает матрицу феромонов размером n×n с начальным значением 1.0:
pheromone = [[1.0 for _ in range(n)] for _ in range(n)]

Построение решений муравьями
Для каждого муравья создается пустое решение и выбираются предметы:
for ant in range(n_ants):

Выбор предмета на основе вероятностей
Для каждого допустимого предмета вычисляется вероятность выбора на основе феромона и удельной ценности:
prob = (avg_pheromone ** alpha) * (value_per_weight[i] ** beta)

Стохастический выбор методом рулетки
Предмет выбирается случайно с учетом вычисленных вероятностей:
r = random.random()

Обновление феромонов

Испарение: уменьшение всех значений феромона:
pheromone[i][j] *= (1.0 - evaporation_rate)

Усиление: добавление феромона на ребрах лучших решений:
pheromone[i][j] += reinforcement

### Временная сложность
Временная сложность — O(n_iter × n_ants × n²).

### Почему: 
наличие внешнего цикла по итерациям (n_iter раз), внутреннего цикла по муравьям (n_ants раз) и операций выбора предметов (до n² операций на муравья) приводит к сложности O(n_iter × n_ants × n²).




# Контрольный Вопрос 
19. Точность и скорость
Какой компромисс существует между точностью приближенного алгоритма и скоростью его
работы?

Основной компромисс заключается в том, что для достижения более высокой точности, как правило, требуется выполнить больше вычислительных операций, что увеличивает время работы алгоритма, тогда как более быстрые алгоритмы часто получаются за счет упрощения вычислений, использования эвристик или рассмотрения лишь части данных, что неизбежно снижает точность.
